Guides to the project's Computer Engineering disciplines, diagnostic scoring, and mock exam tools.

Scoring deficiency tags provide objective, topic-by-topic diagnostic feedback immediately following a submitted mock exam. Scores are grouped into three categories:
  • Deficient (<60%): Identifies topics requiring immediate remediation. Automatically creates a drill set link in your remediation queue.
  • Satisfactory (60%–74%): Indicates passing familiarity, but requires problem-solving speed improvements.
  • Proficient (75%–100%): Meets this project's proficiency threshold.
To preserve exam integrity, deficiency tags are never shown during the countdown.
The project organizes questions into six disciplines, each with five domains:
  1. Network Engineer
  2. Systems Operations Engineer
  3. Computer Systems Architect
  4. Software Developer
  5. Algorithm Engineer
  6. Digital Design Engineer

See the Disciplines page for every domain. Mock exams use the project's draft TOS weights for domains and the cognitive levels Remember, Understand, Apply, and Analyze, together with the chosen Easy, Medium, and Hard mix. These are project weights, not official PRC percentages.

  • Guest: Anonymous practice drills only. A score is displayed in the current tab, but no account or score history is stored.
  • Student: Mock exams, saved results, the exam generator, remediation, and topic requests.
  • Examiner: Add, edit, and import question-bank items. An administrator assigns this role.
  • Admin: Manage accounts and roles, unlock accounts, review password requests, and oversee questions and topic requests.
The Practice Exam page lets examinees select one or more domains within their registered discipline, a question count, time limit, and difficulty mix. Every selected domain receives questions. Difficulty is a target and may vary when the bank is short of a level. The separate Mock Exam uses the fixed 100-question domain × cognitive TOS blueprint.
