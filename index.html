Frequently Asked Questions

Scoring deficiency tags are computed immediately upon submitting an exam. A domain score under 60% receives a Deficient tag, 60%–74% receives Satisfactory, and 75%+ is awarded Proficient. These tags appear only after exam completion to ensure authentic test-taking conditions.
Practice Exams are short drills open to guests. Mock Exams are timed simulations that save attempt history and generate topic-by-topic analytics for registered users. These are project simulations, not official licensure exams.
Students and admins can build custom mock sets by selecting question count, time limits, and difficulty profiles (Easy, Medium, Hard). Custom mode activates linked sliders that balance to 100%.
Registered examinees can use the Request Form to propose specialized exams (e.g., Network Security or Memory Hierarchy and Cache). Requests enter a pending queue for admin review.
